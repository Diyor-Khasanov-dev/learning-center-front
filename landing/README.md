# A.L.I.A — Academic Lead & Intelligence Assistant

A.L.I.A (Academic Lead & Intelligence Assistant) is an all-in-one ERP & CRM management platform designed for learning centers, language academies, and IT schools.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
